# Quick Currency Calculator

A real-time currency converter web application. Fast, clean, and user-friendly.

## ✨ Features

- 🔄 Real-time exchange rates
- ⚡ Instant conversion
- 📱 Fully responsive
- 🎨 Clean, modern UI
- 🚀 Fast performance
- 💾 Local storage for favorites

## 🛠 Tech Stack

- React
- TypeScript
- Tailwind CSS
- Exchange Rate API
- Vercel hosting

## 🚀 Live Demo

[https://quick-currency-calc.vercel.app/](https://quick-currency-calc.vercel.app/)

## 💻 Running Locally

```bash
git clone https://github.com/Ahmedelhadidyy/Quick-currency-calc.git
cd Quick-currency-calc
npm install
npm run dev
```

## 📖 Usage

1. Select currencies (From/To)
2. Enter amount
3. See real-time conversion
4. Results update instantly

## 🎓 What I Learned

- Real-time API integration
- State management with React hooks
- Responsive component design
- Error handling
- User experience optimization
